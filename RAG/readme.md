1. HNSW নামটা ভাঙি

HNSW = Hierarchical Navigable Small World

চারটা শব্দ:

Hierarchical → multiple layers
Navigable → graph-এর connection follow করে target-এর দিকে এগোনো
Small World → relatively few connections দিয়েই দূরের nodes-এ পৌঁছানো যায়
Graph → vectors/nodes-এর মধ্যে connections

সবচেয়ে important: HNSW একটা graph-based vector index।
